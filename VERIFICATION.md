- PHP 8.5.9 (Windows CLI): PHPUnit 11.5.56 — **124 теста, 514 проверок, ошибок нет**.
- Итерация 5: DeepL заменён на `OpenAiTranslator` — перевод через любой OpenAI-совместимый `chat/completions` API (DeepSeek, Moonshot Kimi, OpenRouter и т.п.). Конфигурация: `TRANSLATOR_API_KEY`, `TRANSLATOR_API_URL` (любой HTTPS-хост без встроенных доступов), `TRANSLATOR_MODEL`; опциональная `TRANSLATOR_TEMPERATURE` (0–2, по умолчанию не отправляется — части провайдеров, например Kimi k2.6+, разрешена только их температура).
